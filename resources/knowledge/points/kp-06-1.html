KP 6.1关节空间规划
重点 考点 ★★★★★

关节空间规划（Joint-Space Planning）是直接在关节变量空间中规划各关节角度随时间的变化 q(t)。规划时只需给定起止点的关节位置（及速度、加速度），通过插值函数生成各关节的时间轨迹，无需考虑末端在笛卡尔空间的具体路径形状。

💡 路径与轨迹的区别

路径（Path）是末端执行器在空间中走过的几何曲线，仅含位置信息，不含时间信息；轨迹（Trajectory）= 路径 + 时间律，不仅规定"走到哪里"，还规定"何时走到、以多快速度走到"。同一条路径可以用不同的时间律（匀速、加速、减速）走完，产生不同的轨迹。轨迹规划的核心任务就是为给定的路径施加合适的时间律。

关节空间规划的核心优势：

  • 不直接求雅可比逆：关节插值本身不会因雅可比求逆而数值发散，但生成的运动仍可能经过运动学奇异附近，必须结合任务路径、速度放大和后续控制要求检查；
  • 计算简单：每个关节独立规划，无需复杂的逆运动学求解；
  • 约束直接：关节速度、加速度、力矩约束可直观施加。
⚠️ 关节空间规划的局限

关节空间规划的缺点是末端轨迹形状不可控：各关节独立插值时，末端执行器在笛卡尔空间中走出的是一条复杂的曲线（而非直线），且无法保证中途不与障碍物碰撞。因此，当任务要求末端走特定几何路径（如焊接直线焊缝、装配圆弧轨迹）时，必须采用笛卡尔空间规划。

💡 规划的连续性要求

轨迹规划需满足不同阶的连续性要求：位置连续（C⁰）保证轨迹不跳跃；速度连续（C¹）避免无限加速度冲击；加速度连续（C²）避免加加速度（jerk）突变引起的机械振动。三次多项式满足 C¹，五次多项式满足 C²，这是选择插值阶数的基本依据。

MATLAB 使用jtraj进行关节空间轨迹规划
% 关节空间轨迹规划：jtraj五次多项式插值
L1 = Link('d', 0, 'a', 0, 'alpha', 0);
L2 = Link('d', 0, 'a', 0.4, 'alpha', 0);
L3 = Link('d', 0, 'a', 0.3, 'alpha', 0);
robot = SerialLink([L1 L2 L3], 'name', '3DOF');
q0 = [0 0 0];            % 起始关节角
q1 = [pi/2 pi/3 pi/4];     % 终止关节角
t  = 0:0.05:2;            % 时间序列(0~2s)
% jtraj: 五次多项式插值，返回位置/速度/加速度
[q, qd, qdd] = jtraj(q0, q1, t);
figure;
subplot(3,1,1); plot(t, q);   title('关节位置');
subplot(3,1,2); plot(t, qd);  title('关节速度');
subplot(3,1,3); plot(t, qdd); title('关节加速度');
robot.plot(q);  % 动画演示关节运动
