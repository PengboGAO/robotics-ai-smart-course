KP 6.2三次多项式插值
重点 ★★★★★

三次多项式插值（Cubic Polynomial Interpolation）是关节空间最常用的轨迹规划方法。设关节角 q(t) 为时间的三次多项式：

三次多项式轨迹
q(t) = a₀ + a₁ t + a₂ t² + a₃ t³

共有 4 个未知系数 a₀、a₁、a₂、a₃，需 4 个边界条件求解。典型边界条件为起止点的位置与速度：

边界条件（4 个）
q(0) = q₀,   q(tf) = qf,   q̇(0) = v₀,   q̇(tf) = vf

由 q̇(t) = a₁ + 2a₂ t + 3a₃ t² 代入边界条件，解得系数：

系数解析解
a₀ = q₀,   a₁ = v₀
a₂ = [ 3(qf−q₀) − (2v₀+vf) tf ] / tf²
a₃ = [ −2(qf−q₀) + (v₀+vf) tf ] / tf³
✅ 三次多项式的特性

当起止速度均为零（v₀ = vf = 0，即"停-停"轨迹）时，公式简化为 a₀ = q₀、a₁ = 0、a₂ = 3(qf−q₀)/tf²、a₃ = −2(qf−q₀)/tf³。此时位置、速度连续，但加速度在端点不连续（从 0 跳变到 6(qf−q₀)/tf²），可能引起机械冲击。这是三次多项式的主要不足。

MATLAB 三次多项式系数计算与轨迹绘制
% 三次多项式插值：解析法求系数并绘图
q0 = 0;  qf = pi/2;    % 起止位置
v0 = 0;  vf = 0;        % 起止速度(停-停)
tf = 2;                 % 运动时间
% 解析法求系数 a0+a1*t+a2*t^2+a3*t^3
a0 = q0;
a1 = v0;
a2 = (3*(qf-q0) - (2*v0+vf)*tf) / tf^2;
a3 = (-2*(qf-q0) + (v0+vf)*tf) / tf^3;
t  = 0:0.01:tf;
q   = a0 + a1*t + a2*t.2 + a3*t.3;   % 位置
qd  = a1 + 2*a2*t + 3*a3*t.2;       % 速度
qdd = 2*a2 + 6*a3*t;                % 加速度
figure;
subplot(3,1,1); plot(t,q);   ylabel('位置');
subplot(3,1,2); plot(t,qd);  ylabel('速度');
subplot(3,1,3); plot(t,qdd); ylabel('加速度');
