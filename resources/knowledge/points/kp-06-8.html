KP 6.8样条曲线
难点 ★★★★★

当轨迹需经过多个中间路径点（waypoints）时，单一多项式插值会导致高次多项式振荡（Runge 现象）。样条曲线（Spline）通过分段低次多项式并在节点处保持连续性，兼顾光滑性与局部可控性，是多点轨迹规划的主流方法。

B 样条（B-Spline）：由基函数 Bi,k(t) 加权控制点构成，具有局部支撑性（移动一个控制点只影响附近 k+1 段）和凸包性（曲线位于控制点凸包内，稳定性好）。k 次 B 样条保证 Ck−1 连续。三次 B 样条（k=3）保证 C² 连续，是最常用形式。

B 样条曲线定义
P(t) = Σi Bi,k(t) · Ci

贝塞尔曲线（Bézier Curve）：由控制点与伯恩斯坦基函数构成，曲线必过首末控制点（端点插值），中间控制点"拉"曲线但不一定经过。n 阶贝塞尔曲线由 n+1 个控制点确定，全局性强（移动任一控制点影响整条曲线）。

n 阶贝塞尔曲线
P(t) = Σi=0n Cni ti (1−t)n−i · Pi,   t ∈ [0,1]
特性 B 样条 贝塞尔曲线
端点插值不一定过首末控制点必过首末控制点
局部性强，控制点影响局部弱，控制点影响全局

适用场景多点复杂轨迹、局部调整外形设计、平滑过渡

💡 B 样条的节点向量与连续性控制

B 样条的连续性由阶数 k 与节点向量共同决定。均匀节点向量（节点等距分布）计算简单但端点不插值；准均匀节点向量（两端重复 k+1 次）使曲线通过首末控制点，是机器人轨迹最常用的形式；非均匀节点向量（如根据弦长参数化）可在控制点密集处提高分辨率。通过在中间节点处重复 k 次，还可人为降低该处连续性，实现轨迹"折角"效果，适用于需要精确经过某些路径点的场景。

✅ 多点轨迹的规划策略

当轨迹需经过多个中间路径点时，有三种常见策略：① 分段三次多项式——每段独立三次多项式，节点处匹配速度保证 C¹，但加速度不连续；② 三次 B 样条——整体 C² 连续，光滑性最佳，但不一定精确经过路径点（需用插值型 B 样条）；③ LSPB 串联——每段用 LSPB，节点速度匹配，兼顾匀速与连续性。工业控制器多采用 B 样条或分段多项式方案。

MATLAB B样条轨迹生成(多点轨迹)
% B样条轨迹生成：三次B样条(多点轨迹规划)
% 定义路径点(waypoints)
wp = [0 0.5 1.0 1.5 2.0 1.5 1.0;
      0 0.8 0.5 0.3 0.0 0.4 0.7]';
N = 100;   % 采样点数
t_wp   = linspace(0, 1, size(wp,1));
t_fine = linspace(0, 1, N);
% 三次样条插值(等价于C2连续的插值型B样条)
q1 = spline(t_wp, wp(:,1), t_fine);
q2 = spline(t_wp, wp(:,2), t_fine);
% 数值微分求速度
qd1 = gradient(q1, t_fine);
qd2 = gradient(q2, t_fine);
figure;
subplot(2,1,1);
plot(t_fine, q1, 'b-', t_wp, wp(:,1), 'ro');
ylabel('位置'); legend('B样条轨迹', '路径点');
subplot(2,1,2);
plot(t_fine, qd1, 'r-'); ylabel('速度');
