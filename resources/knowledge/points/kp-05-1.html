KP 5.1拉格朗日法
重点 难点 考点 ★★★★★

拉格朗日法（Lagrangian Formulation）是一种基于能量观点建立系统动力学方程的方法。它从系统的动能与势能出发，通过拉格朗日函数自动消去理想约束力，直接得到与广义坐标数目相同的运动微分方程。其核心优势在于只需标量运算（能量），无需分析约束力，对多自由度串联机器人尤为便利。

ABB子模型边界

本章符号算例统一解释为ABB IRB 1200的A2–A3平面教学子模型。m、I、质心位置均为课程符号或教学设定值，不是ABB厂家动力学参数；完整六轴力矩预测必须使用可追溯的辨识参数并另行验证。

对于 n 自由度机器人，定义广义坐标 q = [q₁, q₂, ..., qₙ]ᵀ，拉格朗日函数 L 定义为系统动能 K 与势能 V 之差：

拉格朗日函数定义
L = K − V

则第 i 个广义坐标对应的广义驱动力（关节力矩）τᵢ 由拉格朗日方程给出：

拉格朗日方程（第二类拉格朗日方程）
τi = d/dt (∂L / ∂q̇i) − ∂L / ∂qi　　(i = 1, 2, ..., n)

该方程的物理意义可分解为两项：

  • 第一项 d/dt(∂L/∂q̇ᵢ)：广义动量对时间的变化率，反映惯性效应；
  • 第二项 ∂L/∂qᵢ：拉格朗日函数对广义坐标的偏导，反映动能位形依赖项和有势力项。
✅ 拉格朗日法建模四步法

① 确定广义坐标 q；② 计算系统总动能 K；③ 计算系统总势能 V；④ 代入拉格朗日方程，化简得到 τ = f(q, q̇, q̈)。

⚠️ 注意事项

拉格朗日法虽然推导过程系统化，但能量表达式中包含复杂的偏导数运算，对于自由度较多的机器人，符号推导工作量随自由度呈非线性增长。这也是工程中常借助 MATLAB Symbolic Math Toolbox 或递归牛顿-欧拉法的原因。

MATLAB ABB A2–A3教学子模型拉格朗日推导
% ABB IRB 1200 A2–A3平面教学子模型；参数为教学设定
syms q1 q2 qd1 qd2 t real
m1=2; m2=1; l1=1; l2=0.8; lc1=0.5; lc2=0.4;
I1=0.5; I2=0.2; g=9.81;
% 质心位置（广义坐标的函数）
xc1=lc1*cos(q1);  yc1=lc1*sin(q1);
xc2=l1*cos(q1)+lc2*cos(q1+q2);  yc2=l1*sin(q1)+lc2*sin(q1+q2);
% 质心速度平方
vc1sq=(diff(xc1,q1)*qd1)^2+(diff(yc1,q1)*qd1)^2;
vc2sq=(diff(xc2,q1)*qd1+diff(xc2,q2)*qd2)^2+(diff(yc2,q1)*qd1+diff(yc2,q2)*qd2)^2;
% 动能K、势能V、拉格朗日函数L=K-V
K=0.5*m1*vc1sq+0.5*I1*qd1^2+0.5*m2*vc2sq+0.5*I2*(qd1+qd2)^2;
V=m1*g*yc1+m2*g*yc2;  L=K-V;
% 拉格朗日方程：tau_i = d/dt(dL/dqd_i) - dL/dq_i
% 使用链式法则：d/dt(dL/dqd_i) = sum_j d2L/dqj_dqd_i * qd_j + d2L/dqdj_dqd_i * qdd_j
syms qdd1 qdd2 real
dL_dqd1=diff(L,qd1);  dL_dqd2=diff(L,qd2);
d_dt_dL_dqd1=jacobian(dL_dqd1,[q1,q2,qd1,qd2])*[qd1;qd2;qdd1;qdd2];
d_dt_dL_dqd2=jacobian(dL_dqd2,[q1,q2,qd1,qd2])*[qd1;qd2;qdd1;qdd2];
tau1=simplify(d_dt_dL_dqd1-diff(L,q1));
tau2=simplify(d_dt_dL_dqd2-diff(L,q2));
disp('tau1='), disp(tau1), disp('tau2='), disp(tau2)
