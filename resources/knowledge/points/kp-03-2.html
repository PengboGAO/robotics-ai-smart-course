KP 3.2经典D-H法
难点 ★★★★★

经典 D-H 法（Standard / Classical D-H）由 Denavit 与 Hartenberg 最初提出，又称标准 D-H 约定。其坐标系建立规则为：坐标系 {i} 固连于连杆 i，zi 轴沿关节 i+1 的轴线方向（等价地，zi-1 轴沿关节 i 的轴线方向），xi 轴沿 zi-1 与 zi 的公垂线方向。在这一约定下，从坐标系 {i-1} 到 {i} 的变换由参数 ai、αi、di、θi 描述。

经典 D-H 法将坐标系变换分解为四次基本变换的乘积，顺序为：先绕 zi-1 转 θi，再沿 zi-1 平移 di，再沿 xi 平移 ai，最后绕 xi 转 αi。

经典 D-H 变换矩阵分解
i-1iT = Rot(z, θi) · Trans(z, di) · Trans(x, ai) · Rot(x, αi)
经典 D-H 连杆变换矩阵通式（3-1）
i-1iT = ⎡ cθi   −sθicαi   sθisαi   aicθi ⎤
             ⎢ sθi   cθicαi   −cθisαi   aisθi ⎥
             ⎢ 0     sαi     cαi     di ⎥
             ⎣ 0     0       0       1 ⎦

其中 cθi = cos θi，sθi = sin θi，cαi、sαi 同理。该矩阵左上角 3×3 子块为旋转矩阵，第四列前三行为平移分量。经典 D-H 法的优点是概念直观，缺点是在处理平行关节或存在连杆偏置的构型时，参数表可能出现下标不一致的困惑。

变换分解的几何直觉

经典 D-H 变换的四个基本变换可理解为从坐标系 {i-1} "走"到坐标系 {i} 的四步路径：先绕 zi-1 转 θi（对齐 x 轴方向），再沿 zi-1 平移 di（到达公垂线垂足），再沿 x 平移 ai（到达 zi 垂足），最后绕 x 转 αi（对齐 z 轴方向）。每一步对应明确的几何操作，四步乘积即为完整的坐标系变换。理解这一"四步走"的物理图像，是记忆变换矩阵通式的有效方法。

学习建议

不要死记通式（3-1），而应掌握"四步分解"的推导过程。考场上若遗忘通式，可从四个基本变换矩阵 Rot(z,θ)、Trans(z,d)、Trans(x,a)、Rot(x,α) 出发重新连乘推导。这种"从原理推导"的能力比记忆公式更重要，也是机器人学工程师的基本素养。
