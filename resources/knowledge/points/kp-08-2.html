KP 8.2 ABB机器人编程
考点 ★★★★★

ABB机器人是全球工业机器人市场的领导品牌，其编程语言RAPID是工业机器人领域最广泛使用的编程语言之一。掌握RAPID编程和示教器操作，是机器人工程师的核心技能。

💡 RAPID编程核心概念

Module（模块）：程序的组织单元；Routine（例行程序）：相当于函数；robtarget：机器人目标位姿数据类型，包含位置、姿态、轴配置；MoveJ/MoveL：关节运动/线性运动指令。

关键运动指令对比：

  • MoveJ（关节运动）：各关节同时插值，末端轨迹不可预测但速度最快。适合空中点到点移动（避障段）。
  • MoveL（线性运动）：末端在笛卡尔空间做直线运动，轨迹精确可控。适合焊接、涂胶等需要精确路径的任务。
  • MoveC（圆弧运动）：末端走圆弧轨迹，通过起点、辅助点和终点确定圆弧。
RAPID ABB机器人基本运动程序
MODULE MainModule
  ! 定义目标点（位置 + 姿态 + 轴配置）
  CONST robtarget p10 := [[800,0,900],[1,0,0,0],[0,0,0,0],[9E9,9E9,9E9,9E9,9E9,9E9]];
  CONST robtarget p20 := [[800,200,900],[1,0,0,0],[0,0,0,0],[9E9,9E9,9E9,9E9,9E9,9E9]];

  PROC main()
    ! MoveJ: 关节运动到p10，速度v1000，精度fine
    MoveJ p10, v1000, fine, tool0;

    ! MoveL: 线性运动到p20，速度v500，精度fine
    MoveL p20, v500, fine, tool0;

    ! 返回起点
    MoveJ p10, v1000, fine, tool0;
  ENDPROC
ENDMODULE

3. MoveC圆弧运动与I/O控制：以下示例展示圆弧运动指令和数字I/O控制指令的用法。MoveC通过圆心点（cirpoint）和目标点（topoint）确定一段圆弧；SetDO用于输出数字信号控制外部设备（如夹爪、传送带），WaitDI用于等待外部输入信号（如传感器触发）。

RAPID MoveC圆弧运动与I/O控制示例
MODULE MoveC_IO_Module
  ! 定义圆弧起点、辅助点和终点
  CONST robtarget p_start := [[800,0,900],[1,0,0,0],[0,0,0,0],[9E9,9E9,9E9,9E9,9E9,9E9]];
  CONST robtarget p_circle := [[900,100,900],[1,0,0,0],[0,0,0,0],[9E9,9E9,9E9,9E9,9E9,9E9]];
  CONST robtarget p_end   := [[800,200,900],[1,0,0,0],[0,0,0,0],[9E9,9E9,9E9,9E9,9E9,9E9]];

  PROC main()
    ! MoveJ运动到圆弧起点
    MoveJ p_start, v1000, fine, tool0;

    ! 打开夹爪（数字输出信号doGripper = 1）
    SetDO doGripper, 1;

    ! MoveC: 圆弧运动，p_circle为辅助点，p_end为终点
    MoveC p_circle, p_end, v500, fine, tool0;

    ! 关闭夹爪（抓取物体）
    SetDO doGripper, 0;

    ! 等待外部传感器信号（数字输入diSensor = 1），超时10秒
    WaitDI diSensor, 1 \MaxTime:=10;

    ! 条件判断：若传感器到位则放置，否则报警
    IF DInput(diSensor) = 1 THEN
      MoveJ p_end, v500, fine, tool0;
      SetDO doGripper, 1;  ! 释放物体
    ELSE
      TPWrite "传感器未触发，放弃放置";
    ENDIF
  ENDPROC
ENDMODULE
💡 I/O指令要点

SetDO（Set Digital Output）设置数字输出信号，常用于控制夹爪开闭、气缸伸缩、传送带启停等外部设备。WaitDI（Wait Digital Input）等待数字输入信号到达指定状态，常用于同步外部设备（如等待物料到位、等待安全门关闭）。配合IF条件判断和FOR/WHILE循环，可以实现完整的物料检测分拣逻辑。

robtarget数据结构（完整定义）
robtarget := [ [x, y, z], [q1, q2, q3, q4], [cf1, cf4, cf6, cfx], [eax1, eax2, eax3, eax4, eax5, eax6] ]

robtarget由四个分量组构成，共包含位置、姿态、轴配置和外部轴信息：

  • pos [x, y, z]：末端工具在工件坐标系下的三维位置，单位为毫米（mm）。例如 [800, 0, 900] 表示X=800mm, Y=0mm, Z=900mm。
  • orient [q1, q2, q3, q4]：末端姿态的单位四元数表示，描述工具坐标系相对于工件坐标系的旋转。它没有欧拉角万向锁，但 q 与 −q 表示同一姿态；例如 [1, 0, 0, 0] 表示单位旋转。
  • confdata [cf1, cf4, cf6, cfx]：轴配置数据，指定机器人到达目标位姿时各关节所在的象限区间。cf1、cf4、cf6分别对应关节1、4、6的转角象限（0/1/-1），cfx为附加配置。同一末端位姿可能对应多个关节解（逆运动学多解），confdata用于指定使用哪个解。9E9表示不限制该轴配置。
  • extax [eax1~eax6]：外部轴位置值，最多支持6个外部轴（如导轨、变位机）。若无外部轴，所有值设为9E9。
💡 robtarget示例解读

以 [[800,0,900],[1,0,0,0],[0,0,0,0],[9E9,9E9,9E9,9E9,9E9,9E9]] 为例：位置为(800,0,900)mm，姿态四元数为(1,0,0,0)表示无旋转，轴配置全为0表示使用默认象限，外部轴全为9E9表示无外部轴。在示教器中手动移动机器人到目标位置后，可直接读取当前robtarget值，无需手动计算四元数。

⚠ 坐标系标定的重要性

ABB机器人编程前必须完成坐标系标定：包括基坐标系（Base）、工具坐标系（TCP）和工作坐标系（Wobj）。标定精度直接影响机器人的定位精度。常用四点法标定TCP，三点法标定工作坐标系。
