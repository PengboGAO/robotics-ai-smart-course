KP 5.7动力学方程
重点 考点 ★★★★★

无论采用拉格朗日法还是牛顿-欧拉法，最终得到的机器人动力学方程都具有统一的封闭形式：

机器人动力学方程（统一形式）
M(q) q̈ + C(q, q̇) q̇ + G(q) = τ

其中各项的物理意义如下：

  • M(q)：n×n 惯性矩阵（质量矩阵），对称正定，元素 mij(q) 仅依赖位形 q，描述系统的惯性特性；
  • C(q, q̇)：n×n 科氏力与离心力矩阵，元素依赖 q 和 q̇，描述速度耦合效应；
  • G(q)：n×1 重力向量，元素仅依赖 q，描述重力对关节的影响；
  • τ：n×1 关节驱动力矩向量（广义力）；
  • q, q̇, q̈：分别为关节位置、速度、加速度向量。

💡 科氏矩阵与惯性矩阵的关系

科氏力矩阵 C(q,q̇) 与惯性矩阵 M(q) 存在内在联系。定义克里斯托弗尔符号：

cijk = ½ ( ∂mij/∂qk + ∂mik/∂qj − ∂mjk/∂qi )

则 C 矩阵元素为 Cij = Σk cijk q̇k。利用此关系可以证明一个重要性质：Ṁ(q) − 2C(q,q̇) 为反对称矩阵，即机器人的总机械能（动能+势能）变化率 d(K+V)/dt = q̇ᵀτ。当无外力矩输入（τ=0）时，系统机械能守恒。这是能量守恒在动力学方程中的体现，也是计算力矩控制稳定性证明的关键。

💡 惯性矩阵 M(q) 的重要性质

惯性矩阵 M(q) 具有三个关键数学性质，对机器人分析与控制具有重要意义：

  • 对称性：M(q) = M(q)ᵀ，即 mij = mji。这源于动能二次型 K = ½q̇ᵀM(q)q̇ 的对称性，对称矩阵只需存储 n(n+1)/2 个独立元素。
  • 正定性：对任意非零 q̇，有 q̇ᵀM(q)q̇ = 2K > 0（动能为正）。正定性保证 M(q) 可逆，这是前向动力学仿真 q̈ = M⁻¹(...) 的前提，也是控制稳定性分析的基础。
  • 有界性：M(q) 的特征值有上下界 λmin ≤ λ ≤ λmax，且条件数 λmax/λmin 有限。这保证动力学方程良态，数值求解稳定。当机器人接近奇异位形时，条件数增大但仍有限（区别于雅可比矩阵在奇异处趋向无穷）。

这三个性质是机器人控制系统稳定性证明（如计算力矩控制的 Lyapunov 分析）的基本假设，也是参数辨识与自适应控制收敛性分析的理论依据。

⚠️ 静态与动态的区分

当机器人静止（q̇ = q̈ = 0）时，动力学方程退化为 G(q) = τ，即仅需克服重力——这就是重力补偿的基础。当机器人匀速运动（q̈ = 0）时，方程为 C(q,q̇)q̇ + G(q) = τ，需同时克服科氏力与重力。理解不同运动状态下方程的简化形式，有助于工程中的前馈补偿设计。

💡 动力学方程的扩展形式

理想刚体动力学方程 M(q)q̈ + C(q,q̇)q̇ + G(q) = τ 描述的是无摩擦、无扰动的理想情况。实际工程中，机器人还存在关节摩擦、外部扰动与不确定项，扩展后的完整动力学方程为：

含摩擦与扰动的扩展动力学方程
M(q) q̈ + C(q, q̇) q̇ + G(q) + F(q̇) = τ + τext

其中：

  • F(q̇)：摩擦力矩向量，常用库仑+粘性摩擦模型 Fi = fci·sgn(q̇i) + bi·q̇i，fc 为库仑摩擦系数，b 为粘性摩擦系数；
  • τext：外部扰动力矩，包括末端接触力等效到关节的力矩、负载变化、未建模动态等。
✅ 扩展方程的工程意义

摩擦项 F(q̇) 在低速运动时影响显著（库仑摩擦引起"粘滞-滑动"现象），是高精度位置控制的难点。外部扰动 τext 在接触作业中不可忽略。鲁棒控制（如滑模控制）与自适应控制的设计目标，正是在存在 F 和 τext 不确定性的情况下保证控制性能，这正是第7章控制系统的核心议题。

MATLAB ABB A2–A3教学子模型动力学方程
% ABB IRB 1200 A2–A3教学子模型 M(q)qdd+C(q,qd)qd+G(q)=tau
syms q1 q2 qd1 qd2 qdd1 qdd2 real
m1=2;m2=1;l1=1;l2=0.8;lc1=0.5;lc2=0.4;I1=0.5;I2=0.2;g=9.81;
% 惯性矩阵 M(q)（由动能二次型导出）
M11=m1*lc1^2+I1+m2*(l1^2+lc2^2+2*l1*lc2*cos(q2))+I2;
M12=m2*(lc2^2+l1*lc2*cos(q2))+I2;  M22=m2*lc2^2+I2;
M=[M11 M12; M12 M22];
% 科氏力矩阵 C(q,qd)（由克里斯托弗尔符号导出）
h=m2*l1*lc2*sin(q2);  % 公共因子
C=[-h*qd2, -h*(qd1+qd2); h*qd1, 0];
% 重力向量 G(q)
G=[(m1*lc1+m2*l1)*g*cos(q1)+m2*lc2*g*cos(q1+q2);
    m2*lc2*g*cos(q1+q2)];
% 组装动力学方程：tau = M*qdd + C*qd + G
qdd=[qdd1;qdd2]; qd=[qd1;qd2];
tau=simplify(M*qdd+C*qd+G);
disp('tau1='), disp(tau(1)), disp('tau2='), disp(tau(2))
% 正向动力学：已知tau求qdd，qdd = M^{-1}(tau - C*qd - G)
qdd_sol=simplify(M\(-C*qd-G));
disp('零力矩下加速度 qdd ='), disp(qdd_sol)
