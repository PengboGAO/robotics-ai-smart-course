KP 2.2 旋转矩阵
难点 考点 ★ ★ ★

旋转矩阵（Rotation Matrix）R 是一个 3×3 正交矩阵，用于描述两个坐标系之间的姿态关系。所有旋转矩阵构成特殊正交群 SO(3)，即满足正交且行列式为 +1 的矩阵集合。

旋转矩阵的三个核心性质：

  • 正交性：RTR = I，即 RT = R-1，转置即逆；
  • 行列式：det(R) = +1，保证是纯旋转而非反射；
  • 归一性：每一列（行）均为单位向量，且两两正交。

物理意义：旋转矩阵 R 的第 i 列是动坐标系 {B} 第 i 个坐标轴在静坐标系 {A} 中的方向余弦表示。因此 R 既是坐标变换矩阵，也是姿态描述矩阵。

绕三个基本轴的旋转公式如下（按右手定则确定旋转正方向：右手大拇指指向旋转轴正方向，四指弯曲方向即为正旋转方向（从轴正方向观察为逆时针））：

绕 X 轴旋转 θ 角 (2-2)
Rx(θ) = [ 1,    0,       0;
               0,  cosθ,  -sinθ;
               0,  sinθ,   cosθ ]
绕 Y 轴旋转 θ 角 (2-3)
Ry(θ) = [  cosθ,  0,  sinθ;
               0,  1,       0;
 -sinθ,  0,  cosθ ]
绕 Z 轴旋转 θ 角 (2-4)
Rz(θ) = [ cosθ,  -sinθ,  0;
               sinθ,   cosθ,  0;
               0,       0,  1 ]
📌 记忆技巧

三个旋转矩阵的规律：绕哪个轴旋转，该轴所在行和列就保持单位向量（1 在对角线，其余为 0）；剩余 2×2 子块为标准的二维旋转矩阵 [[cosθ, -sinθ], [sinθ, cosθ]]，符号位置因轴而异。

MATLAB 旋转矩阵定义与正交性验证
% 定义符号变量
syms theta

% 绕 X 轴旋转矩阵
Rx = [1 0 0; 0 cos(theta) -sin(theta); 0 sin(theta) cos(theta)]

% 绕 Y 轴旋转矩阵
Ry = [cos(theta) 0 sin(theta); 0 1 0; -sin(theta) 0 cos(theta)]

% 绕 Z 轴旋转矩阵
Rz = [cos(theta) -sin(theta) 0; sin(theta) cos(theta) 0; 0 0 1]

% 验证正交性: R' * R = I (单位阵)
disp('Rx 正交性验证:'); simplify(Rx.' * Rx)
disp('行列式验证:'); simplify(det(Rx))

% 数值示例: 绕 Z 轴旋转 45 度
theta_val = pi/4;
Rz_45 = double(subs(Rz, theta, theta_val))
✅ 考点提示

旋转矩阵的三个性质（正交性、行列式为 1、列向量单位正交）及 Rx、Ry、Rz 三个公式是高频考点，必须能默写并理解其物理意义（每列为动系轴在静系中的投影）。
