KP 3.5正运动学方程
重点 考点 ★★★★★

正运动学的核心任务是将各连杆变换矩阵依次连乘，得到末端坐标系 {n} 相对于基坐标系 {0} 的齐次变换矩阵。设各连杆变换矩阵为 Ai = i-1iT，则 n 自由度机器人的正运动学方程为：

正运动学求解的完整流程可归纳为以下五个阶段：

1
建立坐标系
按 KP 3.4 六步法为每个连杆固连坐标系，确定 zi、xi 轴与原点。
2
列参数表
逐关节量取 a、α、d、θ，填入 D-H 参数表，校验关节变量位置。
3
写 Ai 矩阵
将每行参数代入通式（3-1）或（3-2），写出 n 个 4×4 连杆变换矩阵。
4
矩阵连乘
计算 T0n=A1·A2·…·An，化简三角函数表达。
5
提取位姿
从 T0n 左上 3×3 子块读姿态 R，从第四列读位置 p，必要时转换欧拉角。
正运动学方程（3-3）
0nT = A1 · A2 · A3 · ⋯ · An = ∏i=1n Ai

对于 6 自由度机器人，正运动学方程具体写作：

6 自由度机器人正运动学方程（3-4）
T06 = A1(θ1) · A2(θ2) · A3(θ3) · A4(θ4) · A5(θ5) · A6(θ6)

其中每个 Ai 都是 4×4 齐次变换矩阵，由该关节的 D-H 参数代入通式（3-1）或（3-2）得到。结果 T06 可分块为：

正运动学结果分块（3-5）
T06 = ⎡ R3×3   p3×1 ⎤
          ⎣ 01×3   1 ⎦

左上角 R3×3 为末端姿态旋转矩阵，右上角 p3×1 为末端位置向量。正运动学具有两个重要性质：

  • 解的唯一性：给定一组关节变量 (θ1,…,θn)，末端位姿 T0n 唯一确定——这是与逆运动学多解性相对的关键差异。
  • 连续性：T0n 是关节变量的连续可微函数，这一性质是后续雅可比矩阵（速度级运动学）的理论基础。
分解技巧：腕部前移与腕部分离

对 6 自由度工业机器人，常将前 3 个关节（手臂）与后 3 个关节（腕部）分开处理：T06 = T03 · T36。其中 T03 决定腕部中心的位置，T36 决定末端相对腕部中心的姿态。这种"位置-姿态解耦"是球腕构型机器人逆运动学可解析的根本原因。

例题：ABB IRB 1200 A2–A3平面教学子链

为单独观察肩、肘角对腕心位置的影响，先把ABB IRB 1200的A2–A3定位部分投影为RR平面教学子链。设两段等效长度为l1、l2，该简化仅用于推导与查错，不替代第3.6节的六轴参考链。

按经典 D-H 约定，ABB A2–A3平面教学子链的参数为：

  • 关节 1：a1=l1，α1=0，d1=0，θ1（变量）
  • 关节 2：a2=l2，α2=0，d2=0，θ2（变量）

代入通式（3-1）得 A1、A2，连乘后末端位姿为：

ABB A2–A3平面教学子链末端位姿（3-8）
T02 = ⎡ c12   −s12   0   l1c1+l2c12 ⎤
          ⎢ s12   c12    0   l1s1+l2s12 ⎥
          ⎢ 0      0      1       0 ⎥
          ⎣ 0      0      0       1 ⎦

其中 c1=cos θ1，s1=sin θ1，c12=cos(θ1+θ2)，s12=sin(θ1+θ2)。末端位置 (x, y) = (l1c1+l2c12, l1s1+l2s12)，末端姿态角 φ = θ1+θ2。这一结果几何意义明确：末端位置是两连杆向量首尾相接的矢量和，姿态角为两关节角的累加——正是平面几何的直观结论，但通过 D-H 法可严格推导得出。
