KP 6.9轨迹优化
了解 ★★★★★

轨迹优化（Trajectory Optimization）是在满足运动学/动力学约束的前提下，寻找使某个性能指标最优的轨迹。它是轨迹规划的高级形式，将规划问题转化为约束优化问题求解。

常见的优化目标包括：

  • 时间最优：在关节速度、加速度、力矩约束下，使运动时间 tf 最小。典型方法为"切换曲线法"（switching curve），在速度-位置相平面内沿约束边界加速/减速。
  • 能量最优：最小化驱动能量 ∫τᵀq̇ dt，适合电池供电的移动机器人与协作机器人，降低能耗延长续航。
  • 冲击最小：最小化加加速度（jerk）∫q⃛² dt，使运动尽可能平滑，减少机械磨损与振动，适合精密装配与医疗机器人。
轨迹优化一般形式
min J = ∫₀tf L(q, q̇, q̈, t) dt
s.t.　qmin ≤ q ≤ qmax,  |q̇| ≤ Vmax,  |q̈| ≤ Amax,  |τ| ≤ τmax

对于最小 Jerk 优化（min ∫₀tf q⃛² dt），在停-停边界条件（起止速度和加速度均为零）下存在解析解：

最小 Jerk 轨迹解析解
q(t) = q0 + (qf − q0) · [10s3 − 15s4 + 6s5]
其中 s = t / tf ∈ [0, 1] 为归一化时间

该解析解与 KP 6.3 中五次多项式的停-停轨迹形式完全一致——这说明五次多项式停-停轨迹本质上就是最小 Jerk 最优轨迹。这一对应关系揭示了多项式插值与最优控制之间的内在联系：选择五次多项式不仅仅是"够用"，而是在最小化加加速度这一物理指标下的最优选择。

💡 时间最优与平滑性的权衡

时间最优轨迹倾向于"贴着约束边界"运动（速度/加速度饱和），这虽然最快，但会产生加速度突变（bang-bang 控制），冲击大。而冲击最小轨迹追求平滑，但运动时间变长。实际工程常采用多目标加权（如 J = w₁·tf + w₂·∫jerk²），在快速性与平滑性之间折中。

✅ 轨迹优化的工程价值

轨迹优化用于在工作范围、速度、加速度、奇异和碰撞约束下改善ABB IRB 1200任务节拍。优化收益必须由同一工位、同一工具负载和同一控制器设置下的前后记录计算，不预设固定百分比；课程结果需在RobotStudio或实体系统复核。

💡 优化求解方法

轨迹优化的求解方法可分为三类：① 解析法——如时间最优的相平面切换曲线法，利用 Pontryagin 极小值原理得到 bang-bang 解，理论优雅但仅适用于简单系统；② 数值优化法——将轨迹参数化（如 B 样条控制点），转化为非线性规划（NLP）问题，用 SQP、内点法求解，灵活通用；③ 智能优化法——遗传算法、粒子群等启发式方法，适合非凸、多模态问题但计算量大。工程中数值优化法（NLP）最为常用。

💡 现代轨迹优化方法：TOPP-RA 与 MPC 实时规划

TOPP-RA（Time-Optimal Path Parameterization via Reachability Analysis）是基于可达性分析的时间最优路径参数化方法。给定一条几何路径（如 B 样条），TOPP-RA 在路径参数-路径参数速度的相平面内，通过前向与后向可达性传播确定最大可行速度曲线，在关节速度、加速度、力矩等多重约束下求得严格时间最优解。与传统切换曲线法相比，TOPP-RA 数值稳定性更好、能统一处理多种约束，是当前时间最优轨迹规划的主流算法，已集成于 OpenSoT、TrajectoryOptimization 等开源库中。

MPC 实时轨迹规划（Model Predictive Control）将轨迹规划与反馈控制融合为在线滚动优化问题：在每个控制周期内，基于当前状态预测未来有限时域内的运动，以最优控制序列的第一步作为实际输入，不断滚动更新。MPC 可显式处理关节限位、速度/加速度约束、障碍物避碰等不等式约束，且具备对模型误差与外部扰动的闭环修正能力。随着嵌入式算力提升与快速 QP 求解器的成熟，MPC 已在协作机器人安全运动规划、自主驾驶轨迹决策等领域得到广泛工程应用，代表了实时轨迹规划的发展方向。

MATLAB 最小Jerk轨迹优化与代价计算
% 最小Jerk轨迹优化(解析解实现)
q0 = 0;  qf = pi/2;   % 起止位置
tf = 2;               % 运动时间
t  = 0:0.01:tf;
s  = t / tf;            % 归一化时间 s in [0,1]
% 最小Jerk解析解: 10s^3 - 15s^4 + 6s^5
q  = q0 + (qf-q0)*(10*s.3 - 15*s.4 + 6*s.5);
% 速度/加速度/加加速度(jerk)
qd   = (qf-q0)*(30*s.2 - 60*s.3 + 30*s.4) / tf;
qdd  = (qf-q0)*(60*s - 180*s.2 + 120*s.3) / tf^2;
qddd = (qf-q0)*(60 - 360*s + 360*s.2) / tf^3;
% 计算Jerk代价积分
jerk_cost = trapz(t, qddd.2);
fprintf('最小Jerk代价 J = %.6f\n', jerk_cost);
figure;
subplot(2,1,1); plot(t,q,'b'); ylabel('位置');
title('最小Jerk轨迹');
subplot(2,1,2); plot(t,qddd,'r'); ylabel('Jerk');
