KP 7.2 位置PID控制
重点 ★★★★★

位置PID控制是将PID控制策略直接应用于机器人关节位置跟踪问题的方法。控制目标是使关节实际位置 q(t) 跟踪期望轨迹 qd(t)，位置误差定义为：

位置误差
e(t) = qd(t) − q(t)
位置PID控制律
τ(t) = Kp·e + Ki·∫e dt + Kd·ė
τ 为关节驱动力矩，qd 为期望关节角，q 为实际关节角

在机器人控制中，位置PID控制通常以独立关节控制的形式实现：每个关节配备独立的PID控制器，忽略关节间的耦合动力学。这种简化在低速运动或关节耦合较弱时效果良好，但在高速、高加速度运动中，由于科里奥利力和离心力等非线性耦合项的影响，控制精度会显著下降。

💡 工程实现要点

实际机器人控制器中，位置PID常采用离散化实现（位置式或增量式），并加入积分限幅（anti-windup）机制防止积分饱和。微分项通常配合低通滤波器以抑制噪声放大。

Ziegler-Nichols 参数整定方法是工程中最经典的PID参数整定法之一，其核心步骤如下：

1
仅比例控制
设 Ki=0, Kd=0，仅用比例控制 Kp，从小到大逐步增大
2
找临界增益
系统输出产生等幅振荡时的 Kp 值记为临界增益 Ku
3
测临界周期
记录等幅振荡的周期 Tu（振荡一个完整周期的时间）
4
计算PID参数
Kp=0.6Ku, Ki=2Kp/Tu, Kd=Kp·Tu/8
5
微调优化
根据实际响应曲线，手动微调三个参数以获得最佳性能
MATLAB PID控制仿真（二阶系统）
% === 二阶系统PID控制仿真 ===
% 被控对象：G(s) = 1 / (s^2 + 2*s + 1)
% 期望：跟踪阶跃信号，超调 < 20%，调节时间 < 3s

% PID参数（Ziegler-Nichols整定后微调）
Kp = 6.0;
Ki = 4.0;
Kd = 2.0;

% 构建PID控制器传递函数
s = tf('s');
G_plant = 1 / (s^2 + 2*s + 1);   % 被控对象
C_pid = Kp + Ki/s + Kd*s;          % PID控制器

% 闭环系统
sys_cl = feedback(C_pid * G_plant, 1);

% 阶跃响应仿真
t = 0:0.01:8;
[y, t] = step(sys_cl, t);

% 绘制响应曲线
figure;
plot(t, y, 'b-', 'LineWidth', 2); hold on;
yline(1, 'r--', '期望值');
xlabel('时间 (s)'); ylabel('输出');
title('PID控制阶跃响应');
legend('PID响应', '设定值');
grid on;

% 性能指标分析
info = stepinfo(sys_cl);
disp('超调量: '); disp(info.Overshoot);
disp('调节时间: '); disp(info.SettlingTime);
disp('上升时间: '); disp(info.RiseTime);
