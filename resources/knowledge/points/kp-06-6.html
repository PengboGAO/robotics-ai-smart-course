KP 6.6直线插补
重点 ★★★★★

直线插补（Linear Interpolation）使末端执行器从起点 p₀ 到终点 pf 沿空间直线运动。位置与姿态分别插值：

位置直线插值
p(t) = p₀ + s(t) · (pf − p₀)

其中 s(t) ∈ [0, 1] 为归一化路径参数，可施加匀速、三次或五次时间律。姿态插值通常采用以下方法：

  • 轴角法（Axis-Angle Linear Interpolation）：将起止姿态转换为旋转轴-旋转角表示，对旋转角线性插值，姿态变化最短路径；
  • 四元数球面线性插值（Quaternion SLERP）：用单位四元数在四维球面上大圆弧插值，光滑无奇异，是工业主流方法；
  • RPY 角线性插值：直接对欧拉角线性插值，简单但可能产生姿态非最短路径与万向锁问题。
💡 姿态插值的选择

直线插补中"直线"仅指位置轨迹，姿态变化并非沿直线。姿态变化路径取决于插值方法：四元数 SLERP 给出姿态空间的最短路径（大圆弧），而 RPY 线性插值可能绕远路。对姿态精度要求高的任务（如焊接、装配），推荐使用四元数 SLERP。

MATLAB 笛卡尔空间直线插补
% 笛卡尔空间直线插补
p0 = [0.4; 0.0; 0.5];   % 起点
pf = [0.6; 0.2; 0.3];   % 终点
tf = 2;                   % 运动时间
N  = 50;                 % 插补点数
t  = linspace(0, tf, N);
s  = t / tf;               % 归一化路径参数(匀速)
% 位置直线插值: p(t) = p0 + s*(pf-p0)
P = p0 + s' .* (pf - p0)';
% 绘制三维直线轨迹
figure;
plot3(P(:,1), P(:,2), P(:,3), 'b-o', 'LineWidth', 1.5);
hold on;
plot3(p0(1), p0(2), p0(3), 'rs', 'MarkerSize', 10);
plot3(pf(1), pf(2), pf(3), 'gs', 'MarkerSize', 10);
grid on; xlabel('X'); ylabel('Y'); zlabel('Z');
title('笛卡尔空间直线插补轨迹');
legend('轨迹', '起点', '终点');
