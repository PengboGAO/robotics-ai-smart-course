KP 6.7圆弧插补
难点 ★★★★★

圆弧插补（Circular Interpolation）使末端沿空间圆弧运动。空间中不在同一直线上的三点确定唯一一个圆，圆弧插补的核心是由三点求圆心与半径，再沿圆弧参数化运动。

1
输入三点
给定起点 P₁、中间点 P₂、终点 P₃
2
定平面
由 P₁P₂、P₁P₃ 叉积求平面法向量 n
3
求圆心
解 P₁P₂、P₁P₃ 中垂面与平面交点得圆心 C
4
算半径角
半径 r=|P₁C|，圆心角 θ=∠P₁CP₃
5
参数化
沿圆弧以角度参数 ψ(t) 插值得 P(t)
圆弧参数方程（圆心 C，半径 r，起始角 ψ₀）
P(t) = C + r [ cos ψ(t) · u + sin ψ(t) · v ]

其中 u、v 为圆弧所在平面内两正交单位向量（由 P₁−C 归一化得 u，v = n × u），ψ(t) = ψ₀ + s(t)·θ 为随时间变化的圆心角，s(t) 为时间律。

⚠️ 三点共线判别

当 P₁、P₂、P₃ 三点共线时，叉积 (P₂−P₁)×(P₃−P₁) = 0，无法确定圆弧平面，圆弧退化为直线。实际插补前必须进行共线判别：若叉积模长小于阈值，则自动退化为直线插补，避免数值奇异。

💡 空间圆弧 vs 平面圆弧

ABB IRB 1200常需完成空间圆弧任务。课程先由三点确定圆弧平面，在平面内插值位置，再独立插值姿态；进入RobotStudio时还要比较课程插值结果与RAPID MoveC的路径和配置选择。

MATLAB 空间三点圆弧插补
% 空间三点圆弧插补
P1 = [0.4; 0.0; 0.5];   % 起点
P2 = [0.5; 0.1; 0.4];   % 中间点
P3 = [0.6; 0.0; 0.3];   % 终点
% 求圆弧平面法向量
n = cross(P2-P1, P3-P1);  n = n / norm(n);
% 求圆心C(中垂面交点)
A = [2*(P2-P1)'; 2*(P3-P1)'; n'];
b = [norm(P2)^2-norm(P1)^2; norm(P3)^2-norm(P1)^2; n'*P1];
C = A \ b;              % 圆心
r = norm(P1 - C);       % 半径
u = (P1 - C) / r;       % 平面正交基u
v = cross(n, u);         % 正交基v
th1 = atan2(v'*(P1-C), u'*(P1-C));
th3 = atan2(v'*(P3-C), u'*(P3-C));
s  = linspace(0, 1, 50);
th = th1 + s*(th3-th1);  % 圆心角插值
P  = C + r*(cos(th)*u + sin(th)*v);
figure; plot3(P(1,:),P(2,:),P(3,:),'b-','LineWidth',2);
hold on; plot3(P1(1),P1(2),P1(3),'rs',P3(1),P3(2),P3(3),'gs');
grid on; xlabel('X'); ylabel('Y'); zlabel('Z'); title('空间圆弧插补');
