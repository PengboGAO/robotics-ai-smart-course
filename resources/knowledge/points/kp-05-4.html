KP 5.4牛顿-欧拉法
难点 考点 ★★★★★

牛顿-欧拉法（Newton-Euler Formulation）是一种基于矢量力学的递推方法。它直接应用牛顿第二定律（平动）和欧拉方程（转动），通过两趟递推完成动力学计算：先从基座向末端正向递推速度与加速度，再从末端向基座反向递推力与力矩。

牛顿-欧拉法的核心方程包括：

  • 牛顿方程（平动）：Fi = mi aci，描述质心平动；
  • 欧拉方程（转动）：Ni = cIi αi + ωi × (cIi ωi)，描述绕质心转动。

整个算法分为正向递推与反向递推两个阶段，如下所示：

1
正向递推
基座 → 末端
递推各连杆速度 ω、加速度 α 与质心加速度 ac
2
反向递推
末端 → 基座
递推各连杆受力 F 与力矩 N，得到关节驱动力矩 τ
💡 牛顿-欧拉法的核心优势

递归牛顿—欧拉逆动力学在常见串联链实现中可达到随关节数线性增长的计算量，因此适合实时力矩计算。拉格朗日法若直接进行符号展开，表达式会随自由度迅速膨胀，但其复杂度取决于具体算法与实现，不能统一写成固定的O(n⁴)。两种方法在模型和约定一致时应得到相同的关节力矩结果。

✅ 局部坐标系表示技巧

为简化计算，牛顿-欧拉法通常在各连杆局部坐标系中表示速度、加速度和惯性张量。这样惯性张量 iIi 为常数矩阵（不随位形变化），避免了拉格朗日法中惯性张量随位形变化的复杂性。坐标系间的变换通过旋转矩阵 R 完成。

MATLAB ABB A2–A3教学子模型牛顿—欧拉递推
% ABB IRB 1200 A2–A3平面教学子模型；参数为教学设定
function tau = ne_two_link(q, qd, qdd)
  m1=2;m2=1;l1=1;l2=0.8;lc1=0.5;lc2=0.4;I1=0.5;I2=0.2;g=9.81;
  s1=sin(q(1));c1=cos(q(1));s12=sin(q(1)+q(2));c12=cos(q(1)+q(2));
  % ===== 正向递推：基座→末端，计算速度与加速度 =====
  w1=qd(1); wd1=qdd(1);                     % 连杆1角速度/角加速度
  w2=qd(1)+qd(2); wd2=qdd(1)+qdd(2);        % 连杆2角速度/角加速度
  ac1=[-lc1*s1*wd1-lc1*c1*w1^2;            % 连杆1质心加速度(含重力)
        lc1*c1*wd1-lc1*s1*w1^2-g];
  a2=[-l1*s1*wd1-l1*c1*w1^2; l1*c1*wd1-l1*s1*w1^2-g]; % 关节2原点加速度
  ac2=[a2(1)-lc2*s12*wd2-lc2*c12*w2^2;    % 连杆2质心加速度
        a2(2)+lc2*c12*wd2-lc2*s12*w2^2];
  % ===== 反向递推：末端→基座，计算力与力矩 =====
  F2=m2*ac2; N2=I2*wd2;  tau2=N2;          % 连杆2(末端无外力)
  F1=m1*ac1; N1=I1*wd1;                     % 连杆1牛顿-欧拉方程
  % 力矩递推：r×F的z分量(平面叉乘=标量)
  tau1=N1+N2+(lc1*c1*F1(2)-lc1*s1*F1(1))+(l1*c1*F2(2)-l1*s1*F2(1));
  tau=[tau1; tau2];
end
