KP 2.6 齐次变换矩阵
重点 难点 ★ ★ ★

齐次变换矩阵（Homogeneous Transformation Matrix）T 是一个 4×4 矩阵，将旋转与平移统一在单一矩阵中，同时描述坐标系间的姿态与位置关系。这是机器人运动学最核心的数学工具。

齐次变换矩阵结构 (2-8)
ATB = [  R(3×3),  p(3×1);
                0(1×3),    1  ]

其中 R 为 3×3 旋转矩阵，描述 {B} 相对 {A} 的姿态；p 为 3×1 平移向量，描述 {B} 原点在 {A} 中的位置；底部行 [0 0 0 1] 为齐次坐标的辅助行，保证矩阵可逆且乘法封闭。

图2-5 齐次变换矩阵分块结构：R（蓝色）描述姿态，p（橙色）描述位置

坐标变换作用：齐次变换矩阵将点在 {B} 中的齐次坐标 [x, y, z, 1]T 映射到 {A} 中：

齐次坐标变换 (2-9)
[xA, yA, zA, 1]T = ATB · [xB, yB, zB, 1]T

复合变换：多个坐标系间的变换可通过矩阵连乘级联。若 {C} 相对 {B} 的变换为 BTC，{B} 相对 {A} 的变换为 ATB，则 {C} 相对 {A} 的变换为：

复合变换（连乘） (2-10)
ATC = ATB · BTC

这一性质是机器人正运动学的理论基础：从基座到末端的位姿可通过各连杆齐次变换矩阵的连乘得到。注意矩阵乘法不满足交换律，因此变换顺序至关重要。

逆变换：已知 ATB 求 BTA 时，无需对 4×4 矩阵求逆，可利用旋转矩阵正交性简化计算：

齐次变换矩阵的逆 (2-11)
BTA = (ATB)-1 = [  RT,  -RTp;
                                 0,     1 ]

即逆变换的旋转部分取 R 的转置，平移部分取 -RTp。这一技巧在逆运动学与坐标系转换中频繁使用，比直接求逆矩阵更高效且数值更稳定。

💡 SE(3) 群

所有齐次变换矩阵构成特殊欧氏群 SE(3)，它是 SO(3) 旋转群与三维平移的半直积。SE(3) 在乘法下封闭、有逆、有单位元，这些群性质保证了多连杆变换连乘的数学合法性。

⚠️ 变换顺序不可交换

齐次变换矩阵乘法不满足交换律：ATB·BTC ≠ BTC·ATB。先平移再旋转与先旋转再平移的结果不同。在推导运动学方程时，必须严格按坐标系链的顺序连乘。

MATLAB 齐次变换矩阵构造与复合
% 定义平移向量与旋转角
p = [1; 2; 3];          % 平移向量
theta = pi/4;           % 45 度

% 构造绕 Z 轴旋转的齐次变换矩阵
Rz = [cos(theta) -sin(theta) 0; sin(theta) cos(theta) 0; 0 0 1];
T = [Rz, p; 0 0 0, 1]

% 点在 {B} 中的坐标, 求在 {A} 中的坐标
p_B = [0.5; 0.5; 0; 1];     % 齐次坐标
p_A = T * p_B

% 复合变换: 先平移 T1 再旋转 T2
T1 = [eye(3), [1;0;0]; 0 0 0, 1];   % 平移
T2 = [Rz, [0;0;0]; 0 0 0, 1];       % 旋转
T_total = T1 * T2                   % 复合结果
disp('注意: T1*T2 与 T2*T1 结果不同')
T_reverse = T2 * T1                 % 反序对比
✅ 核心要点

齐次变换矩阵是第 3 章正运动学（D-H 参数法）的直接数学工具。掌握 T 的分块结构、坐标变换作用与复合连乘性质，是学习后续运动学建模的前提。
