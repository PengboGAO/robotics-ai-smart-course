KP 6.5笛卡尔空间规划
重点 考点 ★★★★★

笛卡尔空间规划（Cartesian-Space Planning）是在末端执行器的位姿空间（位置 + 姿态）中直接规划轨迹。规划结果是一条末端在笛卡尔坐标系中的几何路径（如直线、圆弧），再通过逆运动学实时转换为各关节角。

笛卡尔空间规划的典型流程：

1
路径定义
在笛卡尔空间定义几何路径（直线/圆弧）
2
时间标度
对路径参数施加时间律（匀速/多项式）
3
逆运动学
逐点求逆运动学得关节角 q(t)
4
约束校验
校验关节限位、速度、奇异与碰撞
⚠️ 笛卡尔空间规划的挑战

笛卡尔空间规划虽然轨迹直观，但存在三大挑战：① 计算量大——每个插补点都需求解逆运动学；② 奇异问题——路径经过奇异位形时逆解不存在或趋于无穷；③ 不可达问题——部分笛卡尔路径点可能超出工作空间或关节限位。因此实际系统需进行奇异检测与可达性预判。

MATLAB 笛卡尔空间轨迹规划(ctraj+逆运动学)
% 笛卡尔空间规划：ctraj直线插补 + 逆运动学
L1 = Link('d', 0.5, 'a', 0, 'alpha', 0);
L2 = Link('d', 0, 'a', 0.4, 'alpha', 0);
L3 = Link('d', 0, 'a', 0.3, 'alpha', 0);
robot = SerialLink([L1 L2 L3], 'name', '3R');
T0 = robot.fkine([0 0 0]);         % 起点位姿
T1 = robot.fkine([pi/4 pi/3 pi/4]);  % 终点位姿
t  = 0:0.05:2;
Ts = ctraj(T0, T1, length(t));  % 笛卡尔直线插值
q  = zeros(length(t), 3);
% 逐点逆运动学求解关节角
for i = 1:length(t)
    q(i,:) = robot.ikine(Ts(i));
end
p = transl(Ts);  % 提取末端位置
figure; plot(t, q); title('关节角轨迹');
figure; plot3(p(:,1),p(:,2),p(:,3),'b-o');
grid on; xlabel('X'); ylabel('Y'); zlabel('Z');
title('末端笛卡尔空间轨迹');
