KP 2.4 四元数
难点 ★ ★ ★
🔄 轴角表示法（旋转向量）

除欧拉角外，轴角表示法（Axis-Angle）是另一种紧凑的旋转描述：用单位旋转轴 n（3 参数，含单位约束）和转角 θ（1 参数）共 4 个参数表示一次旋转，也称旋转向量表示法。其旋转矩阵由罗德里格斯（Rodrigues）公式给出：

轴角-旋转矩阵（罗德里格斯公式） (2-5b)
R = cosθ·I + (1 - cosθ)·n·nT + sinθ·n×

其中 I 为 3×3 单位阵，n× 为旋转轴 n 的反对称矩阵（叉积矩阵）。轴角表示与四元数关系密切：单位四元数 q = [cos(θ/2), sin(θ/2)·n] 是轴角 (n, θ) 的“半角”编码。它避免了欧拉角的万向锁，但仍有 q 与 −q 表示同一旋转的双覆盖性质；轴角本身在 θ=0 和 θ=π 附近也存在轴选择或符号多义性。

四元数（Quaternion）是扩展复数至四维的超复数，由 Hamilton 于 1843 年提出。单位四元数用 4 个参数描述三维旋转：

四元数定义 (2-6)
q = w + x·i + y·j + z·k = [w, x, y, z]T

其中 w 为实部，(x, y, z) 为虚部，满足归一化约束 w2 + x2 + y2 + z2 = 1。四元数也可用旋转轴 n 与转角 θ 表示：q = [cos(θ/2), nxsin(θ/2), nysin(θ/2), nzsin(θ/2)]。

四元数相比欧拉角的优势：

  • 无万向锁：单位四元数可连续表示姿态，但 q 与 −q 对应同一旋转，插值前需统一符号分支；
  • 计算高效：乘法运算比旋转矩阵少（4 参数 vs 9 参数）；
  • 插值平滑：支持球面线性插值（SLERP），姿态过渡自然平滑，无突变。

四元数到旋转矩阵的转换公式如下，这是工程实践中连接两种表示的桥梁：

四元数转旋转矩阵 (2-6a)
R = [ 1-2(y²+z²),   2(xy-wz),   2(xz+wy);
       2(xy+wz),  1-2(x²+z²),   2(yz-wx);
       2(xz-wy),   2(yz+wx),  1-2(x²+y²) ]

四元数乘法遵循Hamilton 乘法规则，基本虚数单位满足 i² = j² = k² = ijk = -1。两个四元数 q₁ = (w₁, v₁) 与 q₂ = (w₂, v₂) 的乘积为：

四元数 Hamilton 乘法 (2-6b)
q₁ ⊗ q₂ = (w₁w₂ - v₁·v₂,   w₁v₂ + w₂v₁ + v₁×v₂)

其中 v₁·v₂ 为向量点积，v₁×v₂ 为向量叉积。四元数乘法对应旋转的复合：q₁⊗q₂ 表示先按 q₂ 旋转再按 q₁ 旋转的结果，且不满足交换律（q₁⊗q₂ ≠ q₂⊗q₁）。

MATLAB 四元数 Hamilton 乘法示例
% 定义两个四元数 q1, q2 (w, x, y, z)
q1 = [0.7071, 0, 0.7071, 0];   % 绕 Y 轴旋转 90 度
q2 = [0.7071, 0.7071, 0, 0];   % 绕 X 轴旋转 90 度

% 方法1: 使用 Aerospace Toolbox 的 quatmultiply
q_prod = quatmultiply(q1, q2)

% 方法2: 手动实现 Hamilton 乘法
w1 = q1(1); v1 = q1(2:4)';
w2 = q2(1); v2 = q2(2:4)';
q_manual = [w1*w2 - dot(v1,v2), ...
            (w1*v2 + w2*v1 + cross(v1,v2))']

% 验证: 四元数乘法不满足交换律
q_rev = quatmultiply(q2, q1)
disp('q1*q2 与 q2*q1 结果不同, 证明不可交换')

四元数广泛应用于航天器姿态控制、机器人末端姿态规划、3D 图形学与游戏引擎中。其缺点是不如欧拉角直观，且需注意双覆盖性质（q 与 -q 表示同一旋转）。
