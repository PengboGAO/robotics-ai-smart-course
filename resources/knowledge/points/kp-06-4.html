KP 6.4LSPB 直线抛物线混合
难点 考点 ★★★★★

LSPB（Linear Segment with Parabolic Blend，直线抛物线混合）是一种兼顾匀速运动与速度连续的轨迹规划方法。它在中间段采用匀速直线运动（恒速），在起止段采用抛物线过渡（匀加速），从而既保证速度连续，又能在大部分时间保持恒定速度，适合需要稳定作业速度的场景。

LSPB 轨迹分为三段：

  • 第1段（抛物线加速段）：t ∈ [0, tb，匀加速，速度从 0 线性增至 v；
  • 第2段（直线匀速段）：t ∈ [tb, tf−tb，恒速 v；
  • 第3段（抛物线减速段）：t ∈ [tf−tb, tf]，匀减速，速度从 v 线性减至 0。
LSPB 各段表达式（停-停，起止速度为0）
① q(t) = q₀ + ½ a t²,   0 ≤ t ≤ tb
② q(t) = qb + v (t − tb),   tb ≤ t ≤ tf − tb
③ q(t) = qf − ½ a (tf − t)²,   tf − tb ≤ t ≤ tf
其中 qb = q(tb) = q₀ + ½ v·tb 为过渡段终点位置

其中加速度 a 与过渡时间 tb、匀速 v 的关系为 v = a·tb，且由位移约束可解得：

过渡时间与匀速的约束关系
tb = (q₀ − qf + v·tf) / v,   a = v / tb

⚠️ LSPB 的加速度不连续

LSPB 保证了速度连续（C¹），但加速度在分段切换点（tb 和 tf−tb）处存在跳变（从 +a 跳到 0，再从 0 跳到 −a），即不满足 C² 连续。这会在分段点产生有限的加加速度（jerk）冲击。对冲击敏感的精密作业，应改用五次多项式或高阶样条。

💡 匀速段 v 的取值约束

匀速 v 不能任意取值。匀速 v 需满足双重约束：下限 v ≥ (qf−q₀)/tf（保证 tb ≥ 0），上限 v ≤ 2(qf−q₀)/tf（保证匀速段存在，即 tb ≤ tf/2）。同时 v 也不能过大，否则加速度超出关节驱动能力。加速度需满足约束：

加速度约束
a = v / tb ≤ amax　，　即 v ≤ amax · tb

实际中需在速度上限与加速度上限之间折中选择 v。

MATLAB LSPB轨迹计算与绘图
% LSPB直线抛物线混合轨迹规划
q0 = 0;  qf = pi/2;    % 起止位置
tf = 2;                 % 总时间
v  = 0.7*(qf-q0)/tf;     % 匀速(需满足约束)
tb = (q0 - qf + v*tf) / v;  % 过渡时间
a  = v / tb;                % 加速度
t  = 0:0.01:tf;
q  = zeros(size(t));
% 三段轨迹：加速段-匀速段-减速段
for i = 1:length(t)
    if t(i) <= tb
        q(i) = q0 + 0.5*a*t(i)^2;         % 抛物线加速
    elseif t(i) <= tf - tb
        q(i) = q0 + 0.5*a*tb^2 + v*(t(i)-tb);  % 直线匀速
    else
        q(i) = qf - 0.5*a*(tf-t(i))^2;    % 抛物线减速
    end
end
qd  = gradient(q, t);    % 数值求导: 速度
qdd = gradient(qd, t);   % 加速度
figure;
subplot(3,1,1); plot(t,q);   ylabel('位置');
subplot(3,1,2); plot(t,qd);  ylabel('速度');
subplot(3,1,3); plot(t,qdd); ylabel('加速度');
