# 数据与AI使用边界

## 学生数据

- 公开演示版不采集姓名、学号、手机号、账号、面部、语音等个人信息。
- 本机记录只保存在浏览器本地，可由学习者主动导出或清除。
- 正式教学接入学校平台后，按最小必要原则采集数据，并明确用途、保存期限、访问权限和删除机制。
- 申报材料中的学习数据必须脱敏、同口径、可追溯，不得将演示数据写成真实成效。

## AI助教

- 一级提示：定位问题类别，不给答案。
- 二级提示：提供检查顺序和方法。
- 三级提示：学生尝试后给局部公式、测试或代码检查支架，不生成完整作业。
- 终评与迁移任务：关闭生成式提示，只保留资料检索和过程日志。
- AI输出不能直接作为模型参数、实验数据或安全结论，必须由学生复算、教师抽检。

## 工程安全

- 浏览器和MATLAB结果仅用于课程模型验证。
- 碰撞、工具负载、工件坐标、控制器配置和实体运行必须在完整RobotStudio站点及现场安全流程中检查。
- 缺少原始文件或日志的项目统一标注“待验证”。
- 实体运行前执行低速、单步、限位、急停和工作区隔离检查，最终放行由教师或实验室授权人员完成。

## 学术诚信

- 学生提交物须列明AI工具、使用时间、提示级别、采纳内容和人工复核方式。
- 不得提交AI生成但本人无法解释、无法复算的模型、代码和结论。
- 参数、公式、图片和代码须标注来源；社区模型与厂商模型的适用范围必须区分。
