# 《机器人学基础》AI智慧课程建设依据与申报对照

## 一、建设定位

本课程不是把资源搬到网页，而是以学习产出为起点，把机器人学知识组织为工程任务，要求学生提交模型、代码、仿真和反证四类直接证据。AI承担入口诊断、错误定位、检查路径提示和局部支架，教师负责目标、任务、量规、学情判断和安全放行，学生负责完整建模、编程、复算与结论。

## 三、建设要素对照

| 建设要素 | 本课程实现 | 可检查位置 | 后续真实材料 |
|---|---|---|---|
| 学生中心与产出导向 | 4项学习产出对应任务、证据、量规和补证 | 首页、学习路径、证据档案 | 课程目标达成度原始表 |
| 高阶性、创新性、挑战度 | 多构型建模、一致性验证、约束检查、反例和无AI迁移 | M3、M4、M6 | 学生匿名提交包 |
| 知识图谱与个性路径 | 知识—任务—能力三图联动，入口诊断推荐起点 | 课程图谱、学习路径 | 平台学习路径日志 |
| 常态化AI场景 | 三级提示、提示留痕、AI逐步退出 | AI诊断助教、M6 | 脱敏提示记录 |
| 多类型资源 | 数字教材、交互仿真、工程代码、证据量规 | 数字教材、ABB实验 | 视频、题库、实验任务书 |
| 虚实融合实践 | 浏览器预检与MATLAB复算；RobotStudio和实体站点人工复核 | ABB验证实验 | 站点文件、事件日志、实体记录 |
| 学习评价 | 不以停留时长代替能力；按四类直接证据评价 | 学习证据、教师工作台 | 同口径评分量规与成绩明细 |
| 持续改进 | 缺项自动提示补证，版本管理与自动部署 | 教师工作台、GitHub工作流 | 教学周期改进记录 |
| 安全伦理 | 最小数据、AI声明、人工复核、待验证标识 | 全站提示、AI边界文档 | 学校数据审批和模型清单 |
| 课程思政 | 实事求是、学术诚信、工程安全和结果责任嵌入任务标准 | M1、M4、M6 | 学生证据与教师反馈 |

## 四、申报前必须补齐的真实证据

1. 至少两个教学周期的课程运行证明和课程纳入培养方案、学分学时材料。
2. 真实学生的脱敏任务包：模型、代码、仿真、反证、AI使用声明。
3. 同口径的课程目标达成度计算表、评分量规和抽样复核记录。
4. 课程平台学习日志、诊断—干预—补证记录；不以页面浏览量替代学习效果。
5. RobotStudio完整站点、`tooldata`、`loaddata`、`wobjdata`、碰撞集和虚拟控制器事件日志。
6. 实体机器人执行前安全检查表与教师签字记录。
7. 教材、视频、题库、代码和知识库版本更新记录。
8. 学校关于数据处理、模型调用、政治审查、师德师风和知识产权的审核材料。
