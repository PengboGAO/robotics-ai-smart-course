# 省级智慧课程申报证据清单

本清单用于把申报文字逐项落到可核查证据。网站功能完成不等于教学成效成立；凡涉及学生人数、达成度、提升幅度、满意度、应用轮次和推广单位，均须以脱敏原始记录为依据。

## 二、申报前必须补齐的真实材料

1. 至少两个实际教学周期的课程运行记录，含开课时间、学生范围、有效样本和异常数据处理说明。
2. 脱敏后的入口诊断、模块测评、四类证据量规和无AI迁移测评原始导出。
3. 同一学生至少一组“初稿—AI提示—自主修改—教师复核”的过程样例。
4. ABB RobotStudio工作站文件、控制器或虚拟控制器日志、工具与工件坐标、负载参数和碰撞配置截图。
5. 课程目标达成计算表，写明题目或任务权重、达成阈值、缺考与补交处理规则。
6. 教师根据首轮数据修改任务、教材或评价标准的版本差异记录。
7. 学生知情说明、数据最小化说明、AI使用规范和学术诚信承诺。

## 三、可直接采集的课堂证据

- 课前：匿名画像、入口诊断得分、薄弱知识点与建议起点。
- 课中：任务完成时间、模块测评尝试次数、AI提示级别与问题类型。
- 任务：模型文件、代码版本、仿真日志、错误反证与修正说明。
- 评价：六维量规分项值、评价主体、教师复核意见和补证状态。
- 课后：无AI迁移成绩、迁移作品、补学后再测结果。
- 改进：课程目标达成、共性错误、资源更新条目和下一轮措施。

## 四、数据真实性与表述边界

- GitHub Pages公开版产生的是单浏览器演示记录，不得写成班级教学成效。
- 没有原始记录支撑时，使用“系统已具备”“拟在下一轮采集”或“待验证”，不得写成“显著提升”。
- 证书、立项和课程资源可证明建设基础，不能替代学生学习产出证据。
- 机器人标称参数计算不能替代RobotStudio或实体设备验证。
- 任何申报得分与获奖结果均受真实实施、材料质量和专家评审影响，本项目不作获奖保证。
