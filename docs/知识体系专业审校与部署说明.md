# 《机器人学基础》知识体系专业审校与部署说明

## 1. 课程边界

本课程面向电子信息类本科生，主对象为六轴串联工业机械臂。课程不试图覆盖移动机器人、无人系统、软体机器人和机器人操作系统的全部理论。57个核心知识点承担基础教学，15个工程延伸节点连接ABB、RobotStudio、URDF、碰撞检测、离散控制与ROS 2。扩展内容标为“工程延伸”，不挤占基础理论学时。

## 3. 本轮关键纠错

1. 将“单位四元数全域唯一”改为“无欧拉角万向锁，但存在q/−q双覆盖”。
2. 删除D-H“任意位姿6−2=4”和“首行/末行经验规则即可判真”的过度简化，改用多构型正运动学验证。
3. 全部运动学教学案例统一为ABB IRB 1200-5/0.9；参考关节链与课程等价标准D-H链在五组构型下同时校验位置和姿态。
4. 将“任意6R最多8组逆解”限定为典型球形腕分支；一般6R不能使用该普遍上界。
5. 删除跨品牌型号泛化；产品规格、ROS-Industrial社区参考链和课程等价D-H参数分别标注来源与适用边界。
6. 删除“关节空间规划无奇异问题”；改为“不直接求雅可比逆，但路径仍可能经过奇异构型”。
7. 删除“拉格朗日法固定O(n⁴)”；保留递归牛顿—欧拉常见串联链线性增长的适用条件。
8. 修正“Resolved-Rate Motion Control”为分解速度控制，不再误写为分解加速度控制。
9. 阻抗/导纳控制不再按是否配置外置力传感器绝对划分，改为期望动态关系和因果实现说明。
10. MPC不再直接归入AI；仅在模型、代价或策略含学习组件时说明AI关联。
11. ABB IRB 1200-5/0.9速度上限明确为产品规范三相供电口径；单相供电A4/A5上限降低，实体任务以控制器配置为准。

## 4. 正确性验证层级

| 层级 | 已完成 | 不能替代 |
|---|---|---|
| 结构验证 | 57个ID、标题、文件名与图谱逐项一致；8章数量为6/6/8/8/7/9/8/5 | 学科专家对未来新增内容的复审 |
| 数学验证 | SO(3)正交性与行列式、ABB双链五构型复算、五次时间标度六个边界条件 | 所有教材公式的形式化证明 |
| 工程约束 | ABB关节范围、三相供电最大轴速、课程轨迹峰值速度 | RobotStudio完整站点碰撞、节拍和控制器事件日志 |
| 教学一致性 | 72单元均有产出、任务、证据、标准和补证；每模块8道题 | 真实班级达成度和增值评价数据 |
| AI边界 | 三级提示只定位、给检查路径和局部支架；无AI迁移任务保留 | AI替学生建模、代写完整代码或承担安全放行 |

运行`npm test`可重复执行上述结构和数值检查。任何核心知识文件缺失、元数据不一致、非ABB教学案例回归、ABB双链复算失败或AI阶段门禁缺失都会阻止发布。

## 6. 仍需真实条件验证

1. ABB教学运动链来自公开参考模型，不是某台实体机器人的个体标定模型。
2. RobotStudio站点、RobotWare版本、tooldata、wobjdata、loaddata、碰撞集和事件日志尚未随公开课程提供。
3. 课程网页只进行教学级几何与约束预检，不具备安全认证，不生成实体运行放行结论。
4. 当前学习记录保存在单台浏览器；省级申报所需班级过程数据、增值评价与教师复核需接入校级平台并使用真实脱敏数据。
5. 图谱中的video、animation等字段是资源形态设计元数据；公开部署版仅对实际存在的网页、代码和交互资源提供入口，不虚构视频可用性。
