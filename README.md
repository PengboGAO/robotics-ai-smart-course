# 机器人学基础 AI 智慧课程（部署版）

这是一个可直接部署的学习应用，面向机器人工程专业核心课《机器人学基础》。课程按“预期学习产出—工程任务—直接证据—评价标准—补证改进”组织，包含57项知识目录、六个工程任务、ABB IRB 1200工程验证、三级提示AI助教、智能测评、六维证据量规和教师持续改进工作台。

## 学生使用流程

1. 建立匿名学习档案，完成8题入口诊断。
2. 根据学习处方进入对应模块和知识点资源。
3. 完成模块关键检查点、ABB验证任务和四类证据提交。
4. 使用六维量规开展自评、同伴互评或教师评定。
5. 根据薄弱项补学补证，最后完成无AI迁移测评。

系统同时保存诊断、任务、提示、测评、证据、补证与迁移记录，可导出为JSON学习档案。公开版本数据仅保存在本机，不代表正式课程成绩。

## 本地运行

要求 Node.js 18 或更高版本。

```powershell
npm test
npm start
```

浏览器访问 `http://localhost:4173`。

## GitHub Pages部署

1. 在GitHub新建空仓库。
2. 将本目录内容推送到 `main` 分支。
3. 在仓库 `Settings → Pages → Build and deployment` 中选择 `GitHub Actions`。
4. 工作流 `.github/workflows/pages.yml` 会自动发布。

所有资源均使用相对路径，可部署在用户站点或项目子路径。无需安装前端依赖。

## 数据与AI说明

- 默认仅使用浏览器本机存储，不上传个人信息。
- 页面中的教师看板只统计当前浏览器产生的记录，不展示虚构班级数据。
- 内置“AI助教”是经教师审核的三级诊断提示库，可在无网络条件下使用。
- 智能测评默认使用透明规则生成个性化学习处方；配置学校AI网关后，可在教师边界约束下增强诊断文本。
- AI只定位错误、建议检查路径和提供局部支架，不替学生提交模型、代码、复算结果或工程结论。
- 若接入真实大模型，必须通过学校后端网关调用，不得把API密钥写入前端。在 `assets/runtime-config.js` 中填写网关地址即可切换；网关接收 `course`、`policy`、`type`、`level`、`question`，返回 `{ "answer": "..." }`。
- MATLAB复算结果用于课程模型验证，不代表特定实体机器人的绝对标定结果。
- 未提供RobotStudio站点、工具负载、工件坐标、碰撞集和控制器日志时，碰撞与控制器结论均为“待验证”。

## 目录

- `index.html`：课程应用入口
- `assets/`：课程数据、交互逻辑与样式
- `assets/knowledge-graph.json`：57项知识目录及OBE关联数据
- `resources/textbook/`：原有8章数字教材迁移副本
- `resources/abb/`：ABB IRB 1200可复算代码与结果
- `docs/`：建设依据、申报对照、数据与AI边界
- `docs/省级智慧课程申报证据清单.md`：主张—证据—口径—位置审计表
- `.github/workflows/pages.yml`：GitHub Pages自动部署
